# 获客与增长方案（决策 D5）

> 状态：草案。文中所有数字（转化率、价格、成本、人数）都是**假设**，标为【假设】，上线前需用真实数据校准。没有引用外部统计数据的地方，不代表市场规模已验证。

## 1. 定位

- **一句话**：去印尼（巴厘岛/雅加达）的中国游客专用的离线对话翻译——没网也能懂司机、商贩在说什么，金额不出错。
- **目标用户**：自由行、自己打 Grab/Gojek、点外卖、住民宿/别墅的中国游客；次要：商务出差雅加达的人、在印尼常驻的华人新人。
- **差异点**（对比通用翻译 App）：
  1. 完全离线（落地没卡/信号差/漫游贵时也能用）；
  2. 懂上下文和口语缩写（brp、gk、udh、share lok、50rb）；
  3. 金额由程序换算，不靠 AI 猜（50rb = 5 万盾 ≈ ¥X）；
  4. 场景化：打车接人点、餐厅忌口、酒店报修、外卖骑手。
- **不主打**：多语种、拍照翻译（OCR 为候选功能，见 LingoAI 竞品分析）。

## 2. 定价与转化（D4）

- 免费：首条翻译起 24 小时不限量（D3）。下载期间可用预置常用句（D2）。
- 单次旅行包 30 天 ¥18【提案价】；终身买断 ¥48【提案价】。
- 关键提示：**没网不能买**——在家/机场 Wi‑Fi 时提醒购买（横幅剩余 ≤3 小时提示）。
- 【假设】下载完成→首条翻译 60%；试用→付费 8–15%；付费中终身档占 40%。

## 4. 上线节奏

1. **内测（T−4 周）**：TestFlight 20–50 位即将去巴厘岛的用户（小红书招募），重点收集：下载是否顺利、首条翻译时间、金额是否看懂、短语是否地道（母语者校对 `needsNativeReview` 短语）。
2. **首发（T）**：避开国内长假前一周之内（用户已在路上、没时间下载）；选在长假前 3–4 周，配合攻略作者内容。
3. **旺季（国庆/春节/暑假前 2–3 周）**：集中投放攻略作者 + eSIM 联合；推送「出发前在家下载」提醒（仅本地通知，用户已同意时）。
4. **淡季**：迭代短语库与模型（清单驱动更新，不发版），积累评测语料。

## 6. 两次旅行之间的留存

- 不做骚扰推送；仅在用户设置了「出行日期」时，出发前 3 天本地提醒检查模型更新与下载。
- 终身档的价值说明：「下次去也能用」；旅行包到期前不打扰。
- 短语库按季节/社区真实语料更新（见 `社区真实语料.md`）。
