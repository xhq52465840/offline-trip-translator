# 交互改版方案 v4：打开就能对话，金额最醒目

> 状态：方案 + 线框稿，**本轮不改 App 代码**。线框稿：`docs/wireframes/01–04*.png`（生成脚本在 box 的 `/workspace/wireframes/render.py`）。
> 原则：**好用比好看重要**。核心价值 =「离线时，和当地人谈价、问路，能听懂，不会被坑钱」。

## 2. 新信息架构

```
启动 ─┬─ 首次：语言选择（我说/对方说）→ 开始用（后台下载）
      └─ 之后：对话页（= 首页）
对话页
 ├─ 顶栏：设置 | 我说 X ⇄ 对方 Y（点击切换/交换）| •••（场景、清空、短语本）
 ├─ 状态条（仅在非就绪时出现）
 ├─ 消息流（金额卡片置顶于对应消息）
 ├─ 情境快捷回复（按对方上一句话的内容）
 ├─ 文本输入
 ├─ 「按住说话」大按钮（自动识别语言）
 └─ 「给对方看（面对面）」→ 面对面分屏
设置：购买、隐私、汇率、离线资源详情、界面语言
```
场景网格降级到 ••• → 场景；选择场景只影响快捷回复的排序，不再是入口。

## 3. 各屏规格

### 3.1 对话页（首页）— `wireframes/01_home_conversation.png`
- 冷启动直接进入；保留上次的语言对和对话记录。
- **按住说话**：高度不低于 96pt，宽度占满；松手后翻译。语言判定：说话识别同时跑「我的语言 / 对方语言」两路，选置信度高的那一路；判不准时气泡上给「这是对方说的？」切换按钮（一次点击纠正）。
  - 兜底：长按菜单可强制「我说 / 对方说」（替代现在的两个按钮）。
- **给对方看**：次级大按钮，进入面对面模式。
- 空对话：显示 3 条大号示例句（「多少钱？」「请带我去这个地址」「太贵了」），点一下就发送。
- 每条对方消息：原文（灰）+ 译文（粗）；fallback 时保留「本机模型翻译，质量较低…」标签。

### 3.2 金额卡片 + 情境回复 — `wireframes/02_money_card.png`
- 识别到金额（现有程序化解析）→ 在该消息上方插入**金额卡片**：第一行原币大字（≥ 40pt，例如「Rp 50.000」），第二行 ≈ 人民币（≥ 32pt，强调色），第三行口语读法 + 附加条件（「不含运费」「每人」等，来自关键词规则）+ 汇率日期。
- 数字只由程序生成，不经过模型（延续现有原则）。多个金额就在卡片内逐行列出。点击卡片 → 全屏大字给对方看。
- 卡片单位跟随**界面语言**（修 P3：英文界面显示「50k IDR ≈ ¥19」）。
- **情境快捷回复**（规则引擎，不靠模型）：

| 对方话里有 | 推荐 |
|---|---|
| 金额 | 太贵了，便宜点 / {报价×80%}行吗？/ 含运费吗？/ 好的 / 不要了 |
| 地址、地名、方向词 | 请带我去这里 / 多远？/ 能写下来吗？|
| 时间 | 几点？/ 要等多久？|
| 疑问句 | 是的 / 不是 / 我听不懂 |
| 否定、没有 | 那有别的吗？/ 谢谢 |
| 默认 | 谢谢 / 我听不懂 / 请写下来 |
- 点击即发送（快捷句预置了已校对的译文，不需要模型）；长按可编辑后再发。还价金额由程序算出并取整（Rp 按 1.000 取整）。

### 3.3 面对面分屏 — `wireframes/03_face_to_face.png`
- 上半屏旋转 180°，用对方语言：最新一条「我说的」译文（大字）+ 金额卡片 + 「Tahan untuk bicara」按钮。
- 下半屏：我说的原文 + 金额（含 ≈¥）+ 「按住说中文」按钮 + 「退出 / 大字出示」。
- 每半屏的按钮固定识别该侧的语言（这里不用自动判定）。屏幕常亮。

### 3.4 首次打开 — `wireframes/04_first_launch.png`
- 只做两件事：选「我说」和「对方说」（默认值按系统语言和地区推断），点「开始用」。
- 点开始后立即在后台下载模型（Wi‑Fi 优先；蜂窝网络下给一个轻提示），然后进入对话页。下载进度显示在对话页状态条上。
- 购买、隐私、Apple 语言包说明都不出现在首屏。

## 4. 状态设计（不再用阻断弹窗）

| 状态 | 表现 | 仍可用 |
|---|---|---|
| 模型下载中 / 没就绪 | 状态条「理解能力准备中 28%」；对方的长句先走 Apple 直译，加「快速翻译」标签 | 快捷回复、常用句、金额卡片、Apple 翻译 |
| Apple 语言包缺失 | 状态条「印尼语离线包未下载 · 去下载」（调用系统下载）；翻译改用本机模型，加低质量标签 | 本机模型、快捷句、金额 |
| 两者都缺 | 状态条变成警示色；输入后只显示「暂时不能翻译，可以试试这些句子」+ 快捷句 | 快捷句、金额 |
| 离线 | 已就绪时不提示（离线本就是卖点）；只有在需要下载时才提示「连上网后自动继续」| 全部已下载功能 |
| 识别失败 / 没听清 | 气泡「没听清，再说一次」+ 「请对方打字」按钮 | — |

## 5. 国际化（zh + en）
- 新增文案全部写入 `i18n/strings.json`，用 `scripts/i18n.py gen` 生成；`check` 必须为 0 告警。
- 新 key 示例：`home.hold_to_talk`=按住说话/Hold to talk；`home.show_partner`=给对方看/Show to them；`money.excl_shipping`=不含运费/excl. shipping；`reply.too_expensive`=太贵了，便宜点/Too expensive, lower please；`onboard.i_speak`=我说/I speak；`onboard.they_speak`=对方说/They speak；`status.preparing`=理解能力准备中 %d%%/Preparing %d%%。
- 快捷句的对方语言译文（id/en/zh）属于数据，放在 TripCore 短语资源里，由母语者复核。
- 金额单位按界面语言格式化（修 P3）。

## 6. 无障碍
- 按住说话：VoiceOver 标签「按住说话，松开翻译」；为 VoiceOver 用户提供「点一下开始、再点一下结束」模式。
- 金额卡片作为一个整体朗读：「对方报价 5 万印尼盾，约 19 元人民币，不含运费」。
- Dynamic Type 到 AX5 时不截断：金额卡片换行，快捷回复改为纵向列表。
- 对比度不低于 4.5:1；不只用颜色表达状态（状态条要带文字）。
- 触控目标不小于 44pt；面对面上半屏也提供 VoiceOver 标签（对方语言）。
- 尊重「减弱动态效果」。

## 7. 成功指标
| 指标 | 目标 |
|---|---|
| 首次打开到第一次翻译的时间（中位数） | < 30 秒（现状需经过准备列表）|
| 首次会话里至少完成 1 次翻译的比例 | ≥ 80% |
| 快捷回复使用率（每次会话） | ≥ 30% 的会话至少点一次 |
| 「这是对方说的？」纠正率 | < 10%（衡量自动语言判定）|
| 面对面模式使用率 | ≥ 20% 的会话 |
| 下载期间的流失率 | 比现状低 |
| 可用性测试：5 位没见过本 App 的人完成「问价并还价」 | 5 人中至少 4 人无提示完成 |
埋点只在本机计数（不上传）；TestFlight 阶段通过可选的反馈导出收集。
