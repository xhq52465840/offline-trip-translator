## 2. 公开来源评测集 `public_eval.jsonl`（528 条，全部来自公开数据，无自写句子）

| 来源 | 条数 | 任务 | 说明 |
|---|---|---|---|
| Tatoeba ind→cmn | 93 | mt_id_zh | 按旅行关键词（打车/住宿/吃饭/价格/钱/问路/看病/求助/时间）筛选；繁体参考用 OpenCC 转简体 |
| FLORES-200 devtest | 60 | mt_id_zh | 同样按关键词筛选后随机 60 句（seed 0） |
| Wikivoyage phrasebook | 149 | mt_id_en | 只取打车、住宿、钱、吃饭、购物、问路、求助、看病、基础等章节；去掉带空位 `___` 的模板句 |
| STIF-Indonesia test | 226 | slang_norm | ≤25 词、去掉被脱敏数字（xxxnumberxxx）的句子；参考为正式印尼语 |

- 每条记录 `source_dataset`、`license`、`src_id`（可追溯到原始 ID），场景由关键词自动标注（粗分类）。
- **与训练数据不相交**：与 `finetune/out/*` 的全部原文做 token Jaccard ≥ 0.6 去重（训练数据本身是模板生成，未用任何公开数据）。
- 许可：文件混合了 CC BY-SA 4.0 / CC BY 2.0 FR / MIT 内容，整体按 CC BY-SA 4.0 对待并保留逐条署名。
- 评测方式（建议，脚本待接）：mt_id_zh 用 chrF++ / COMET 对参考；mt_id_en 走「模型→英文」或人工判断；slang_norm 让模型把口语句翻成中文后人工抽检，或先做「口语→正式印尼语」再比对参考（chrF）。

## 3. 自写用例的公开佐证

- `public_data/slang_coverage.json`：我们用例/训练模板里用到的 36 个缩写中，28 个能在 kamus-alay 词表查到对应正式词，25 个在 STIF 测试集的真实推文里出现过。
  - 词表里**查不到**的：lok、kalo、otw、tggu、dong、kak、ongkir、cod（多是新兴网约车/电商用语或称呼语；kalo、dong 在 STIF 里出现过）。这些仍只有自写/经验依据，建议找母语者确认。
- `public_data/selfwritten_backing.json`：60 条自写评测用例里有 **33 条**至少包含一个公开词表中的俚语缩写（逐条列出），即这些用例的「俚语」部分有公开来源佐证；整句和参考答案仍是自写。
- 金额写法（50rb、1,5jt、Rp 50.000）：STIF 真实句子里有 `rb` 用法；没有找到带标注的公开金额数据集。

## 4. 建议
1. 自写 60 条继续作为「场景理解（上下文/指代/金额）」主评测——公开数据集都没有多轮上下文和金额换算标注。
2. 新增 `public_eval.jsonl` 作为「直译 + 口语理解」公开基线，每次换模型/微调后跑一遍，防止只对自写数据过拟合。
3. 微调增强：可用 STIF train（MIT）和 Tatoeba ind–eng（CC BY）做俚语/口语增强，但目标中文需另行生成并人工抽检；FLORES 只评不训。
4. 商用前：kamus-alay、IndoCollex 联系作者确认许可；OpenSubtitles / TED 不进训练。
