# UX 改版说明（2026-10-10）

目标：**更垂直**（中国游客在印尼），**更好用**（步骤少、字大、单手可用），**真正的多轮对话**（双方都能看清整场的上下文）。依据见《场景与痛点研究.md》。

## 1. 原则
1. **核心只有一个通用多轮对话**。场景卡片是可选的：它只给模型补一个场景提示，并提供快捷短语，不做任何场景专用工具（砍价助手、换汇计算器这类都不做）。
2. **整场对话都是上下文**，模型和人看到的是同一份记录。
3. **金额永远清楚**：每个气泡下面都有金额胶囊。
4. 打开 App 后 ≤ 1 步进入对话；所有主要操作拇指够得着。

## 2. 页面结构
```
首页 HomeView
 ├─ 「开始对话」大按钮（不选场景，直接进通用对话）
 ├─ 场景卡片 13 个（两列大卡片）：机场入境 / 打车 · 接车 / 外卖骑手 / 餐厅点餐 / 购物 · 付款 / 换汇 · ATM /
 │   酒店 · 别墅 / 包车 · 快艇 / 按摩 · SPA / 看病 · 药店 / 紧急求助 / 问路 / 闲聊 · 礼貌
 └─ 设置（齿轮）：离线准备、汇率、隐私、购买
对话 ConversationView（同一个页面，场景只影响快捷短语和提示词）
 ├─ 顶栏：对方语言 ▾ ｜ 面对面开关 ｜ 更多（换场景、新对话、清除本机对话）
 ├─ 聊天记录（可滚动的整场历史）
 ├─ 剪贴板提示条（PasteButton）
 ├─ 场景快捷短语条（横向滑动的胶囊按钮）
 └─ 底栏：中文输入框 + 发送；两颗 64pt 高的大按钮「听对方」「我说中文」（按住说话）
面对面模式：上半屏是对方语言的同一份记录（旋转 180°，给坐在对面的人看），下半屏是中文记录
```

## 3. 聊天记录（双语气泡）
数据由 `TripAppModel.Transcript.rows(messages, viewer:, rate:)` 生成，有单元测试。

| 字段 | 我的视角（viewer = .me） | 对方视角（viewer = .partner，面对面上半屏） |
|---|---|---|
| 左右位置 | 对方在左，我在右 | 对方自己的话在右，我的话在左 |
| 大字 | 中文：对方的话显示理解后的中文；我的话显示原文中文 | 对方语言：对方原话；我的话显示印尼语译文 |
| 小字 | 另一种语言 | 另一种语言 |
| 说明 | 「字面：…」（理解改写过时显示）；回译不一致时显示「对方看到的意思：…」 | 无 |
| 金额胶囊 | `Rp 50.000 · 5万印尼盾 · ≈ ¥21.7` | 只显示 Rp，不显示人民币 |
| 时间 | HH:mm | HH:mm |
| 操作 | 复制、出示、按其他语言重译 | 无 |

## 4. 多轮上下文（模型）
- `ConversationModel.contextTurns` 把**整场**已完成的消息交给模型：对方的话带原文和中文，我的话带中文和对方看到的译文。
- `TripCore.ContextWindow`：不超过 16 条时全部原样提供；超过时，最近 15 条原样提供，更早的压成一行「前情摘要」。摘要包括开头第一句、出现过的金额、省略了几条，由代码确定性生成，不再调用一次模型，不增加时延，长度 ≤ 120 字。
- `PromptBuilder.scene`：选了场景就写一行「场景：打车（Grab/Gojek 司机）」，不选就不写。

## 5. 快捷短语
- 每个场景 3~6 句，中文 / 印尼语 / 英语都离线预置（`Scenario.phrases`），**上线前需要母语者审校**。
- 点一下立即作为「我」的消息进入记录（不调用翻译、不计试用条数），可以复制和出示。

## 6. 金额胶囊与汇率
- `Money.chips` 复用 `AmountNormalizer`（50rb、1,5jt、250 ribu 等）；印尼盾格式化为 `Rp 1.500.000`。
- 人民币约值：用户在「设置 › 汇率」里手动填写（默认 2300 只是示例），**不联网更新**，界面上标「≈」。

## 7. 易用性
- 大字：主行 `.title3.semibold`，所有字号都用 Dynamic Type 文本样式；Preview 里包含 accessibility2 大字号版本。
- 深色模式：只用系统语义色（secondarySystemBackground、tertiarySystemFill、accentColor），Preview 里有深色版本。
- 触感：开始录音（中等震动）、滑到取消区（警告）、发送（轻震）、复制成功（成功）、失败（错误）。映射关系在 `HapticEvent.kind`，有测试。
- 无障碍：卡片和气泡合并成一个朗读单元；图标按钮都有 accessibilityLabel；金额胶囊朗读为「5万印尼盾，约人民币21.7元」。
- 单手：按住说话的两颗按钮占满底部宽度；发送按钮放在输入框右侧。

## 8. 取消的设计
- 砍价助手（还价按钮）：按要求取消，金额理解改为对所有场景通用。

## 9. 验证情况
- 逻辑（`TripAppModel`、`TripCore`）：有单元测试，Linux 上 `swift test` 全部通过。
- 界面（`App/TripApp/*.swift`）：只做了 `swiftc -parse` 语法检查，**没有在 Xcode 里编译，也没有在真机上看过效果**。
