# 真机验证清单（用户本人；模拟器做不了的部分）

> 前提：s400 已在 GitHub Release `model-s400-v1`（已核对 sha256），清单 v5 只指向它；Mac 循环已结束（r9）。模拟器上 App 的后台下载不可用（系统限制），A 节必须在真机上做。用 Xcode 把 DEBUG 或 TestFlight 版装到 iPhone（6 GB 内存及以上：iPhone 15 Pro / 16 系列 / 17 系列）。
> 每项记 ✓/✗ 和截图，发给盒子写进 `reports/device_<日期>.md`。

## A. 首次准备（连 Wi‑Fi）
1. 删掉旧版重新安装 → 引导页 → 「全部准备」。记录：模型下载耗时（约 986 MB）、进度和剩余时间是否合理、锁屏后是否继续、完成后显示「已就绪」。
2. 下载中途关掉 Wi‑Fi 再打开：应能接着下（断点续传），不会从 0 开始。
3. 切到蜂窝网络：应先弹「要用流量下载吗？」，不会直接下。
4. 存储不足（可用小于约 1.2 GB 时）：应提示「空间不够，还需要…」。

## B. Apple 翻译语言包（每台手机都做；**国行 iPhone 必做**）
1. 设置 → App → 翻译 → 语言：看能否下载 **中文（普通话-中国大陆）、印度尼西亚语、英语（美国）**；打开「设备端模式」。
2. App 准备页上每个语言的状态：已就绪 / 需要下载 / 「系统没有这门语言的离线翻译，将用本机模型翻译（质量较低）」。
   - **国行机重点**：印尼语包能不能下？如果不能，App 应仍可进入对话，印→中走本机模型直译 + 理解。截图记录。
3. 系统区域分别设为中国大陆 / 印尼 / 美国各试一次（能改就改），记录差异。

## C. 飞行模式（核心承诺：完全离线）
开飞行模式（Wi‑Fi、蜂窝都关），逐项测：
1. 我方中文 ← 对方印尼语：粘贴 `50rb belum termasuk ongkos` → 理解结果「5万，不含车费」类，金额正确，有「约 ¥」。
2. 我方中文 → 对方印尼语：打字「太贵了，能便宜一点吗」→ 印尼语译文。
3. 我方英文 ← 对方印尼语：`harganya 100rb kak` → 英文直译 + `≈ $`，金额 Rp 100,000。
4. 我方英文 ↔ 对方中文：各发一句。
5. 我方印尼语 ↔ 对方英文：各发一句（可选）。
6. 面对面模式：两边各按住说一句。
7. 常用句：全屏出示。
8. 汇率：显示内置 / 上次更新的日期，不报错。
9. 任何一步出现「需要联网」「转圈不动」都算 ✗，截图。

## C2. 本机模型兜底（只有某方向 Apple 包装不上时才会走到）
1. 气泡下方有「本机模型翻译，质量较低，重要信息请再确认」。
2. 印→中：主行是中文意思，金额是程序写的「5万」，**不能出现「人民币 / 50元」这类说法**。
3. 中→印：要么是印尼语，要么显示「这句还没翻译出来」，**不能把中文原句当译文**。
4. 印→英：若模型丢了金额，应显示「原文 (Rp 100,000)」而不是模型自己写的数字。
（模拟器 r9 实测兜底质量较低；真机 GPU 下再看一次速度与质量。）

## D. 语音（飞行模式下）
1. 按住说中文（我方）：识别准确、松手出译文；上滑取消有效。
2. 按住「听对方」说印尼语：能否离线识别？不能时应显示「听印尼语暂不可用」，并可改用粘贴。
3. 英语听写同上。
4. 首次使用时麦克风 / 语音识别权限弹窗文字正确（中英两种系统语言各看一次）。

## E. 性能与稳定
1. 连续发 20 条：不闪退、不明显变慢；手机发热程度。
2. 首字延迟（主观：1 秒内出现第一个字为好）。
3. 切到后台再回来、来电打断后回来：对话还在，模型不需要重新下载。
4. 低电量模式下再测 C1。

## F. StoreKit 沙盒
1. App Store Connect 建好两个内购（`pass.trip30`、`unlock.lifetime`，中英文名称见 `docs/appstore/en/iap_and_review_notes.md`），设置 → App Store → 沙盒账户登录。
2. 购买页显示真实价格（不再是「价格暂时取不到」）。
3. 买 30 天通行证 → 显示有效期；删 App 重装 → 「恢复购买」。
4. 买终身 → 显示「已终身买断」；恢复购买有效。
5. 24 小时试用结束后（可改测试时长或等）：只能看字面意思，购买后恢复。

## G. 界面语言
1. 系统语言英文：整套界面英文，无汉字（对方说中文的气泡除外）。
2. 设置 → 界面语言切换后重开 App 生效。

## H. 上架前（用户本人）
1. 公开的隐私政策、支持页网址（可用 GitHub Pages 发布 `docs/appstore/隐私政策.md` 和 `en/privacy_policy.md`），填进 App Store Connect。
2. 审核备注里提供演示视频链接（真机录屏：断网使用 + 金额换算）。
3. 开发者账号的「出口合规」：已设 `ITSAppUsesNonExemptEncryption = false`。
