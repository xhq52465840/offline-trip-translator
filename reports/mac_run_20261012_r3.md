## 需要用户处理 / 给审阅方的问题

T7 未执行。需要用户本人时的步骤：

1. Xcode 打开 `App/TripUnderstand.xcodeproj`，Signing & Capabilities 选 Team；检查 `com.apple.developer.kernel.increased-memory-limit` 是否可用。
2. Scheme → Run → Options → StoreKit Configuration 选 `Products.storekit`；在模拟器里测「单次旅行包（30 天）」「终身买断」「恢复购买」；用 Transaction Manager 退款，确认回到试用状态。

4. 卸载重装后确认 24 小时试用记录仍在（钥匙串）。
5. 真机测速：加载时间、首字延迟、tok/s、内存峰值。
