## 按清单地址下载
`curl -sIL` 清单 URL：`github.com` 返回 HTTP 302，`Location` 在 `release-assets.githubusercontent.com`，接着 HTTP 200，`content-length: 986048640`，`accept-ranges: bytes`。

整文件在 `/tmp/s400.gguf`：986048640 字节，sha256 `691a1b2b1e0b73e3e2156583505300697753184477176301924877f73bf05b0a`。日志里没有对 `example.com` 的请求（过滤条件那一行除外）。

App 自己的后台下载没有成功。模拟器日志（模型已经放到容器里之后，启动仍会建后台会话）：

```
BackgroundSession <94D7084D-336F-402A-B949-3D71C3A3430A> an error occurred on the xpc connection to setup the background session: Error Domain=NSCocoaErrorDomain Code=4097 "connection to service named com.apple.nsurlsessiond" UserInfo={NSDebugDescription=connection to service named com.apple.nsurlsessiond}
```

同一轮更早的尝试里，nsurlsessiond 还拒绝了这个进程（没有 bundle id），模型 URL 上的错误是 `NSURLErrorDomain Code=-1`。重启模拟器、ad-hoc 签名、本机开发证书签名都没有改变这件事。这是这台 iOS 18.3 模拟器上后台会话的限制。没有改 `ModelDownloader`，也没有改成前台下载。

因此三句回归用的是同一份 curl 核对过的文件：复制到 App 的 Application Support `models/trip-mix2-s400-q4_k_m/model.gguf`，并写了 `installed.json`（id、字节、sha256）。App 把它认成已安装：首页约 5 秒出现，准备页「理解能力」为「已就绪」。这不是 App 自己下下来的。
