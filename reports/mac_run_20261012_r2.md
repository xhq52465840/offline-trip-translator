## 错误原文
本轮 Xcode 编译没有 `error:`。

第一次启动 UI 测试时，补丁脚本的标准输出被管道接到 `head`，Python 在写完 Info.plist 之后的 `print` 收到 `BrokenPipeError: [Errno 32] Broken pipe`，随后的 `xcodebuild test` 没有启动。当时 `ios-arm64-simulator` 切片已经写好。去掉 `head` 后重跑，6 个 UI 测试全部通过。这是操作失误，不是工程错误。

## 需要用户处理 / 给审阅方的问题
